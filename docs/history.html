02 / RAW → COMMON CELLS → BASELINE INDEX

Different counts. A shared representation.

MODIS (~1 km) and VIIRS (~375 m) detect thermal anomalies with different resolution, sensitivity and overpass timing. Source counts are converted into common daily cells, then a paired-period scaling baseline is applied.

The sensor transition

2000 → 2012 → 2018 → 2024 → latest NRT

MODIS · 2000
S-NPP · 2012
NOAA-20 · 2018

Overlap calibrates a prototype baseline. NOAA-21 observations begin in 2024; this archive build does not include a NOAA-21 Standard Processing series. Missing years or months stay empty. Thermal anomalies include agricultural burning and other heat sources; these are not unique fires or burned area.
