Road map styles derived from OpenFreeMap liberty and dark, https://openfreemap.org/quick_start/. Label expressions prefer name_en, then name:latin; native-script fallback is removed. Road shields retain their reference numbers. Raster NASA imagery uses separate Natural Earth English place labels. Vector tiles and fonts are served by OpenFreeMap and preserve source attribution (OpenMapTiles and OpenStreetMap). Refresh these style snapshots with prepare-map-styles.js.
